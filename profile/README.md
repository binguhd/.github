## 🖼️ 画质

- 优先获取 **UHD / 4K** 原始分辨率图片，而非压缩缩略图
- 保留 Bing 官方提供的图片元信息（标题、版权、日期、地区）
- 按 **日期 + 地区** 结构化归档，便于检索与脚本调用
- 文件名统一规范，避免重复与覆盖

## ⚙️ 更新

- **每日自动** 抓取九个地区的最新壁纸
- 自动去重：同一张图片在不同地区重复出现时仅保留一份并记录来源地区
- 分类目录归档按 `{年}`，长期可追溯
